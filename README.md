# 🌳 Green Village

Green Village is a Smart Tree Protection & Plantation Application developed using React.js.

## Features

- Register Trees
- Store Tree Locations
- View Registered Trees
- Promote Environmental Awareness

## Technology Used

- React.js
- JavaScript
- HTML
- CSS

## Project Objective

To encourage tree plantation and provide a simple digital platform for monitoring and registering trees in villages.
